# OP7 — Image Processing

## Overview

This folder contains the final practical assignment submitted and approved for the elective course **Image Processing (2025)**, part of the Data Science Diploma Program.

The course covers the fundamental concepts of digital image processing and computer vision, from image representation and enhancement to segmentation and pattern recognition. The practical assignment applies these concepts to real image data using computational techniques.

## Topics Covered

- Digital image representation  
- Color and the human visual system  
- Histogram manipulation  
- Image transforms  
- Convolution-based processing  
- Image enhancement with additive degradation  
- Morphological processing  
- Image sampling and reconstruction  
- Compression techniques  
- Computer vision fundamentals  
- Image segmentation and representation  
- Pattern recognition and interpretation in images  

## Contents

The folder contains the **final practical assignment notebook**, which implements and demonstrates the main techniques studied during the course.
