# Mentorship Project — Space Object and Debris Prediction (2025)

## Overview

This folder contains the project developed during the **Mentorship** of the Data Science Diploma Program (2025):  
**“Predictions in Space: How many satellites and debris will we have?”**

In the last decade, the number of satellites in orbit has grown exponentially due to technological advances and cost reductions (New Space). Along with this growth, the amount of space debris has also increased, becoming a critical problem for space operations and sustainability.

The objective of this project is to analyze historical data about objects in Earth orbit and to develop predictive and/or classification models using supervised and unsupervised learning techniques.

## Project Structure and Deliverables

The project was developed in multiple stages:

- **Practical 1 — Analysis and Visualization:**  
  Initial data exploration and visualization to understand the main characteristics and trends of satellites and space debris.

- **Practical 2 — Exploratory Data Analysis and Data Curation:**  
  Deeper exploratory analysis, data cleaning, preprocessing, and feature engineering to prepare the datasets for modeling.

- **Midterm Video Presentation:**  
  Short presentation summarizing the dataset, the main findings from the first two practical assignments, and the project direction.

- **Practical 3 — Supervised and/or Unsupervised Learning:**  
  Development of machine learning models for prediction and/or classification of orbital objects, including training, evaluation, and interpretation of results.

- **Final Video Presentation:**  
  Final presentation of the complete project, including methodology, modeling approach, and results.

## Project Goals

The project aims to:

- Analyze the historical evolution of satellites and space debris in orbit  
- Study the real operational lifetime of satellites  
- Explore patterns in the distribution of space debris across different orbits  
- Analyze which countries generate more space debris  
- Build models to predict the future amount of space debris and/or classify objects in orbit  

## Data

The project uses historical datasets that include information about:

- Launches and missions  
- Active and inactive satellites  
- Object size, orbit, period, mission type, and lifetime  
- Space debris and non-functional objects  

The raw data is sourced from:  
`https://github.com/EnzoRg/space_debris` (space_debris/data/raw)
