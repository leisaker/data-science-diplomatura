# OP2 — Distributed Programming on Big Data

## Overview

This folder contains the notebooks developed for the elective course **Distributed Programming on Large-Scale Data**, part of the Data Science Diploma Program.

The course introduces the fundamentals of Big Data processing and distributed computing using **Apache Spark**, covering both low-level and high-level APIs. The focus is on understanding how to work with large-scale datasets, how distributed execution works, and how to build data processing and machine learning workflows in a distributed environment.

## Topics Covered

- Introduction to Big Data and distributed data processing  
- Programming patterns and limitations of MapReduce  
- First steps with Apache Spark using Zeppelin notebooks  
- Resilient Distributed Datasets (RDDs): creation, transformations, actions, persistence, and fault tolerance  
- Core concepts of distributed computing: nodes, executors, jobs, stages, tasks, and partitions  
- Spark SQL: DataFrames, Datasets, and connectors to external data sources  
- Machine Learning on large-scale data:
  - Pipelines  
  - Feature extraction and selection  
  - Classification and clustering methods  
  - Model and hyperparameter selection  

## Contents

The folder contains **Zeppelin notebooks (`.zpln`)**.  
Each notebook includes:
- The concepts covered in class  
- The practical exercises completed and submitted to pass the course
