# Data Science Diploma Repository

This repository contains the Jupyter notebooks and assignments completed throughout the Data Science Diploma Program. The materials are organized into folders corresponding to each course, including the core curriculum, elective subjects, and the final mentorship project.

## 📚 Core Courses

### **Data Analysis and Visualization (Análisis y Visualización de Datos)**

Exploratory plots, dashboards, visual encodings, descriptive analysis, and effective communication of insights.

### **Exploratory Data Analysis and Data Curation (Análisis Exploratorio y Curación de Datos)**

Data cleaning, preprocessing, feature engineering, handling missing values, detection of anomalies, and data quality assessment.

### **Introduction to Machine Learning (Introducción al Aprendizaje Automático)**

Fundamentals of machine learning, workflows, basic algorithms, model evaluation, and generalization concepts.

### **Supervised Learning (Aprendizaje Supervisado)**

Regression and classification models, hyperparameter tuning, cross-validation, metrics, overfitting control, and ML pipelines.

### **Unsupervised Learning (Aprendizaje No Supervisado)**

Clustering methods, dimensionality reduction, anomaly detection, similarity metrics, and model interpretation.

## 🧭 Mentorship Project

This section includes the work completed during the **Mentorship Program**, covering project planning, exploratory analysis, model development, validation, and final results.

## 🔍 Elective Courses

The repository also contains notebooks from the three elective courses taken during the program. These courses expand on specific technical and methodological aspects of data science, depending on the selected topics.
