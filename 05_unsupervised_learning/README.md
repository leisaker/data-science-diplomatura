# 05 — Unsupervised Learning

## Overview

This folder contains the practical assignment submitted and approved for the **Unsupervised Learning (2025)** course, part of the Data Science Diploma Program.  
The project focuses on exploratory data analysis, clustering, and representation learning techniques applied to a real-world dataset of professional football players.

The emphasis is on discovering structure in unlabeled data, comparing different clustering approaches, and interpreting the resulting groups in a meaningful, domain-oriented way.

## Skills and Topics Covered

### 🧩 Unsupervised Learning and Clustering
- Introduction to clustering and cluster analysis  
- Evaluation of clustering results  
- K-Means, DBSCAN, Gaussian Mixture Models, and/or hierarchical clustering  
- Choice and justification of hyperparameters (number of clusters, distance metrics, etc.)  

### 📊 Exploratory Analysis and Preprocessing
- Exploratory Data Analysis (EDA)  
- Pairwise visual analysis of numerical variables  
- Feature scaling and normalization  
- Discussion and justification of preprocessing choices  

### 🧠 Representation Learning and Visualization
- Dimensionality reduction / embeddings (e.g., PCA)  
- Visualization of high-dimensional data  
- Use of projections for analysis and/or preprocessing  

## Tools & Techniques

- Python (numpy, pandas, scikit-learn)  
- Jupyter Notebooks  
- Data visualization (matplotlib / seaborn)  
- Clustering workflows  
- Unsupervised learning pipelines  

## Practical Assignment

- **Clustering and Player Profiling with Football Player Data:**  
  Dataset: `male_players.csv` (Kaggle)  
  Performed an end-to-end unsupervised learning analysis on a dataset of professional football players. The project included initial exploratory data analysis, visual inspection of relationships between numerical variables, and a discussion on the need for feature scaling and normalization. Applied and compared at least two clustering techniques, justifying the choice of hyperparameters. Conducted a qualitative analysis of the resulting clusters to interpret player profiles and assess whether players within a cluster could be considered equivalent in terms of roles and skills. Finally, used dimensionality reduction / embedding techniques to visualize the clusters and support the analysis.
