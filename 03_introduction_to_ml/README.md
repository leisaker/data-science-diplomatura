# 03 — Introduction to Machine Learning

## Overview

This folder contains the two practical assignments submitted and approved for the **Introduction to Machine Learning** course.  
The projects focus on understanding and applying core machine learning algorithms, from linear and logistic models to probabilistic and tree-based methods, as well as on learning how to properly evaluate and compare models.

The emphasis is on building end-to-end supervised learning workflows, including model training, validation, performance evaluation, and model selection.

## Skills and Topics Covered

### 🤖 Core Machine Learning Models
- Introduction to machine learning and supervised learning workflows  
- Linear regression and the perceptron algorithm  
- Logistic regression  
- Naive Bayes classifiers  
- Decision trees  

### 📉 Optimization and Learning
- Cost functions and optimization principles  
- Model training and convergence behavior  

### 🧪 Model Validation and Evaluation
- Train / validation / test splits  
- Cross-validation techniques  
- Performance metrics for classification and regression  
- Model selection and comparison based on evaluation metrics  

## Tools & Techniques

- Python (numpy, pandas, scikit-learn)  
- Jupyter Notebooks  
- Supervised learning pipelines  
- Model evaluation and validation workflows
